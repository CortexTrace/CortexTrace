# CortexTrace Security

The official GitHub account of CortexTrace Security, [cortextrace.com](https://cortextrace.com/).

CortexTrace Security is an offensive security consultancy. With your written authorisation, we test applications, networks, cloud estates and people the way an attacker would. We report a weakness only once we have demonstrated it, and we retest after you fix it, so you know the fix holds.

Our registered office is in Melbourne, Australia, and our testers work across the United States, the United Kingdom, Australia, East Africa, Europe and the Middle East. Individual consultants hold qualifications such as OSCP, OSWE, OSEP, OSED, OSCE3 and CISM.
